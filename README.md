# MIT 8103 - Advanced Database Systems Portfolio

## Case Study
Miva Digital Library Management System

## Project Overview
This project demonstrates database design, SQL query
processing, transactions, NoSQL modelling, and
distributed database architecture.

## Tools Used
- DB Browser for SQLite
- SQLite
- MongoDB Community Server
- MongoDB Compass
- diagrams.net
- GitHub

## Portfolio Activities
1. Database Design and Modelling
2. Query Processing and Optimisation
3. Transactions and Concurrency
4. NoSQL and Advanced Data Models
5. Distributed and Cloud Database Exercise

## How to Reproduce the Work
1. Open DB Browser for SQLite.
2. Create a new database.
3. Execute schema.sql.
4. Execute sample-data.sql.
5. Run the query and transaction examples.
6. Follow the MongoDB setup in Portfolio 4.

## Project Limitations
The SQL dataset is small and synthetic.
The cloud architecture is conceptual, not deployed.
